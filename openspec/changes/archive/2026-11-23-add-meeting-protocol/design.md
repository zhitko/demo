# Design

## Context

См. `proposal.md`. Страница должна открываться за секунды и работать на сцене без сети. Паспорт прототипа — `docs/requirements.md`. Числа, помеченные там TBD, не задаём.

## Goals / Non-Goals

**Goals:**

- Один экран: выбрать `.txt`, нажать «Сделать протокол», увидеть три блока, скачать `protokol.txt`.
- Для `samples/transcript-demo.txt` формулировки эталона совпадают с приложением спецификации.
- Повторное нажатие после другого файла заменяет текущий протокол.

**Non-Goals:**

- Распознавание речи, логин, история, календарь, трекер, правка, мобильная вёрстка, напоминания.
- Обработка пустого, нетекстового файла и расшифровки без решений: поведение не задано.
- Показ самой расшифровки рядом с протоколом. Это отдельное изменение, не этот прототип.

## Decisions

- Стек: Vite + React + TypeScript и обычный CSS. Бэкенда нет, поэтому показ не зависит от порта и от API.
- Протокол считает чистая функция `stubProtocol`. Если нормализованный текст совпадает с учебной расшифровкой, функция возвращает эталон. Иначе она достаёт решения, задачи и вопросы по речевым меткам, чтобы другой файл не оставлял на экране предыдущий эталон.
- Живая модель — `protocolFromLlm`, только при `VITE_USE_LLM=true` и заданном `VITE_LLM_URL`. Любой сбой возвращает `null`, и экран берёт заглушку.
- Текст загруженного файла хранится в состоянии страницы вместе с построенным протоколом. Базовый экран текст не показывает: он нужен, чтобы протокол строился из выбранного файла, а не из памяти сервиса.
- Скачиваемый текст собирает `formatProtocol` из тех же строк, что рисует список на экране.

## Risks / Trade-offs

- [Заглушка знает эталон учебной расшифровки] → Об этом сказано в спецификации заранее. Это не скрытая подмена.
- [Разбор произвольного файла грубый] → Для защиты сверяют учебный файл. Другие формулировки не обещаны.
- [Флаг модели может зависнуть на сети] → На лекции флаг выключен. Сбой вызова всё равно падает в заглушку.

## Open Questions

- Нет. Лимит страниц и пустой файл остаются открытыми в `docs/requirements.md` и на задачи не влияют.
