# Proposal

## Why

Руководителю после созвона нужен протокол, который можно показать за минуту и сверить с расшифровкой. Сейчас договорённости теряются: протокол пишут по памяти или не пишут. Прототип проверяет узкий сценарий «файл → три блока → скачивание».

## What Changes

- Одна страница на русском без входа: загрузка `.txt`, кнопка «Сделать протокол», три блока и скачивание.
- Для учебной расшифровки заглушка без сети возвращает эталон из `docs/requirements.md`.
- В одном сеансе хранится только текущий протокол: новая загрузка и повторное нажатие заменяют его.
- Не входит: распознавание речи, логин, история, календарь, трекер, правка протокола, мобильная версия, напоминания, обработка ошибок.

## Capabilities

### New Capabilities

- `meeting-protocol`: протокол из готовой текстовой расшифровки — три блока и скачивание.

### Modified Capabilities

- Нет.

## Impact

- Новое клиентское приложение Vite + React + TypeScript, без бэкенда.
- Учебные данные: `samples/transcript-demo.txt`. Спецификация паспорта: `docs/requirements.md`.
- Внешний вызов модели не нужен для показа. Флаг `VITE_USE_LLM` выключен по умолчанию.
