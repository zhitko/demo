# Design

## Context

См. `proposal.md`. Текст выбранного файла уже лежит в состоянии страницы (`sourceText`) и подменяется целиком при новом нажатии «Сделать протокол». Базовый экран этот текст не рисует.

## Goals / Non-Goals

**Goals:**

- Показать `sourceText` рядом с тремя блоками только после построения протокола.
- Хранить у решения цитату и рисовать её под формулировкой.
- Для учебной расшифровки цитата — точная строка «Ведущий: Принимаем решение: …».

**Non-Goals:**

- Редактор протокола, логин, история, речь, календарь, трекер.
- Подсветка цитаты внутри длинного текста и прыжок к строке.
- Новое поведение для пустого файла: оно по-прежнему не задано.

## Decisions

- Цитата — поле `source` у решения, а не поиск по экрану. Эталон в `src/reference.ts` хранит три строки учебной расшифровки. Для другого файла `stubProtocol` берёт строку целиком, в которой есть «Принимаем решение:».
- Показанный текст — тот, по которому построен текущий протокол, а не файл, выбранный после этого, пока кнопку не нажали снова. Иначе источник и блоки разъедутся.
- Скачивание собирается из тех же строк и цитат, что на экране, через `formatProtocol`.
- Колонка «Расшифровка» стоит справа от трёх блоков. На узком окне она уходит вниз; отдельной мобильной версии нет.

## Risks / Trade-offs

- [Цитата есть только у решений] → Задачи и вопросы в этом изменении без цитат: запрос про решения.
- [Грубый разбор другого файла] → Для учебной расшифровки цитаты заданы эталоном, а не регулярным выражением.
